02 / Approach

Understand it.
Build it.
Show the evidence.

  1. Start with the real problem

    A missing driver, an everyday task, an unclear workflow. Keep the first implementation inspectable.

  2. Make the boundaries visible

    Detection is not verification. Simulated tests are not hardware coverage. A prototype is not a production service.

  3. Leave a useful trail

    Source, setup steps, failure cases and documentation should help the next person pick up the work.

03 / Notes

Field notes

Detection is not support.

A USB ID can match a catalog while the driver is missing, the interface is absent or scanning fails. Antena keeps those states separate.

Read the technical note ↗
What can you verify?

Inspect the detector, diagnostics and simulated tests in the public repository. Hardware observations and known limitations are recorded in its README. To verify physical behavior, use your own supported device and report only sanitized observations.
